## Índice del Repositorio

La estructura de este repositorio se divide en los siguientes directorios y archivos principales:

* **`/` (Raíz del proyecto)**
  * `README.md`: Archivo actual con la información general y el índice de la práctica.
  * `.gitignore`: Archivo para excluir elementos no deseados del control de versiones.

* **`docs/`**
  * `investigacion-bases-de-datos.pdf`: Documento de investigación sobre bases de datos.
  * `estado-del-arte.pdf`: Documento detallando el estado del arte.
  * `caso-de-estudio.pdf`: Documentación del caso de estudio analizado.

* **`entorno/`**
  * `compose.yaml`: Archivo de configuración de Docker Compose para el entorno de la base de datos.

* **`modelo/`**
  * `diagrama-er.png`: Imagen con el diagrama Entidad-Relación de la base de datos.

* **`evidencias/`**
  * `git/`: Carpeta destinada a las evidencias relacionadas con el uso y confirmaciones de Git.
  * `docker/`: Carpeta destinada a las evidencias de la ejecución y configuración de Docker.
